# FaceForge · 产品需求文档(PRD)

> 版本 v0.1 · 2026-07-28 · 状态:草拟,随实现迭代

## 一、目标

自建、**质量优先**的 AI 换脸平台,一套系统覆盖三种场景:

1. **图片换脸** —— 上传源脸 + 目标图 → 高质量换脸图。
2. **视频换脸** —— 上传源脸 + 目标视频 → 逐帧换脸、时序稳定的成片(异步任务 + 进度)。
3. **实时换脸** —— 摄像头/直播画面实时换脸预览。

**成功标准(可测)**
- 图片:1024px 输入,换脸 + 修复 + 遮挡蒙版全链路产出;主观质量对标 FaceFusion 默认管线。
- 视频:1080p、30fps 片段可跑通,产出无明显闪烁(遮挡蒙版 + 逐帧增强)。
- 实时:GPU(NVIDIA 4GB+ 显存)上 ≥ 24fps 预览。
- 全平台**自建、数据不出本机**(隐私优先)。

## 二、用户与场景
- 影视/内容创作者(有授权素材)、特效爱好者、需要自建可控换脸能力的团队。
- **合规红线**:仅限有知情同意的素材;不针对真实私人/公众人物做冒充;产物加溯源水印(C2PA/隐形水印);非法用途(非自愿影像、诈骗、冒充)不支持。

## 三、功能范围

### MVP(P0)
- [P0] 图片换脸:源脸 + 目标图 → 结果图,支持人脸选择(多脸时)、修复增强开关。
- [P0] 视频换脸:异步任务、进度查询、结果下载。
- [P0] 实时换脸:选源脸 → 摄像头实时预览。
- [P0] 模型管理:首次自动下载/缓存所需模型,离线复用。
- [P0] 质量参数:换脸模型档位(256/128)、face enhancer(CodeFormer/GFPGAN)、遮挡蒙版、放大。

### 增强(P1)
- [P1] 批处理、结果历史、任务队列并发控制。
- [P1] 溯源水印(C2PA)、审计日志。
- [P1] 参数预设(质量优先 / 速度优先)。

### 暂不做(Out of Scope)
- 从零训练换脸模型;云托管/多租户;移动端原生 app。

## 四、非功能需求
- **质量优先**:默认最高质量参数(256 换脸器 + 增强 + 遮挡蒙版),速度让步。
- **自建/隐私**:全本地部署,素材与模型不出本机。
- **可部署**:Docker Compose 一键起(GPU 机器);模型卷持久化。
- **可测**:引擎调用可 mock,核心编排/API/UI 有单测;GPU 推理在真机按文档验证。

## 五、验收
- 三种场景各有一条端到端「happy path」在 GPU 机器上跑通并留存产物/说明。
- `pnpm test && lint && type-check`(web)+ `pytest && ruff && mypy`(python)全过。
- 部署文档可复现:clone → 配置 → `docker compose up` → 三功能可用。

## 六、待确认(Open Questions)
1. 目标部署机型/显存(决定实时帧率与视频分辨率上限)。
2. 换脸模型许可:商用需避开 inswapper 非商用授权,选授权明确模型(逐个核对)。
3. 是否要 WebRTC(低延迟实时)还是 WebSocket 传帧(实现简单)——MVP 倾向 WS,P1 上 WebRTC。
