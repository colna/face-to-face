# FaceForge · 部署与验证(需 NVIDIA GPU)🖥️

> 开发沙箱无 GPU/Docker,以下步骤在有 NVIDIA 卡的机器执行并留证。标 🖥️ 的动作沙箱内未跑通。

## 一、前置

- NVIDIA GPU(建议 ≥12GB 显存)+ 驱动 + [nvidia-container-toolkit](https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/latest/install-guide.html)
- Docker + Docker Compose
- 首次启动会下载换脸/增强/解析模型到 `models` 卷(体积较大)

## 二、模型准备 🖥️

`services/face-engine/engine/models.py` 的 `MODEL_CATALOG` 目前 URL/sha256 为占位,真机需替换为真实值:

1. 按 license 选定换脸器(商用走 `hyperswap` 系,勿用 `inswapper`)。
2. 填 `MODEL_CATALOG` 每项的 `url` 与 `sha256`。
3. 启动自检:`GET /models` 返回 `all_ready=true` 即模型就绪。

## 三、一键起栈 🖥️

```bash
cp .env.example .env
docker compose up --build
# web  → http://localhost:3000
# api  → http://localhost:8000/docs
```

`docker-compose.yml` 已声明 `nvidia` GPU device 与 `models` 持久卷。

## 四、接真实引擎(T2.6)🖥️

引擎已把命令组装与执行解耦,真机只需接上真实二进制:

- **图片/视频**:`FaceFusionRunner.build_image_command / build_video_command` 产出的 argv 直接喂 FaceFusion 3.6 `headless-run`;`_default_runner` 用 subprocess 执行。真机需核对 flag 名(不同小版本可能有差异)。
- **实时**:给 `RealtimeSession` 注入 Deep-Live-Cam 帧处理器(`processor: bytes->bytes`)替换默认 GPU stub。

## 五、三场景端到端验证(T5.1)🖥️

| 场景 | 步骤 | 期望 | 留证 |
|------|------|------|------|
| 图片 | web 图片页上传源脸+目标图 → 换脸 | 出图,遮挡处理正确 | 截图 + 输出图 |
| 视频 | web 视频页上传 → 轮询进度 → 下载 | 进度 0→1,产物可播放 | 进度截图 + 输出 mp4 |
| 实时 | web 实时页开前置摄像头 → 开始 | 低延迟看到换脸帧 | 录屏 |

## 六、验证清单

- [ ] 🖥️ `GET /models` → `all_ready=true`
- [ ] 🖥️ 图片换脸产物质量达标(增强 + 遮挡)
- [ ] 🖥️ 视频换脸逐帧完成,进度回写正确
- [ ] 🖥️ 实时换脸帧率达标(≥15fps)
- [ ] 🖥️ `docker compose up` 全栈起,三页可用
